# Экономическое моделирование

Сайт курса «Экономическое моделирование» (Центральный университет, направление «Количественная экономика») и симулятор динамических экономических моделей.

**Сайт:** https://kllkov.github.io/economic_modelling/

## Структура

```
site/                      — то, что публикуется на GitHub Pages
  index.html               — главная: информация о курсе, команда
  models.html              — плитка моделей и симулятор
  assets/css/style.css     — стили
  assets/js/app.js         — интерфейс: плитки, окно настроек, вывод результатов
  assets/js/charts.js      — графики (Chart.js)
  assets/js/solver.js      — метод Ньютона для perfect-foresight систем (трёхдиагональный якобиан)
  assets/js/models/
    registry.js            — каталог моделей: названия, описания «О модели», заглушки
    fisher.js              — модель Фишера: настройки, решатель, формулы
    solow.js               — модель Солоу: настройки, решатель, формулы, основная диаграмма, сходимость
    ramsey.js              — модель Рамсея (с ростом населения): настройки, решатель, формулы
    ispcmpr.js             — модель IS–PC–MPR: настройки, решатель, формулы, диаграммы
  assets/vendor/           — KaTeX, Chart.js (с плагином масштаба chartjs-plugin-zoom и hammer.js) и шрифты (локальные копии)
tests/                     — проверки решателей (числа из лекции, аналитические решения, независимый решатель)
.github/workflows/pages.yml — при пуше в main прогоняет тесты и, если они прошли, публикует сайт на GitHub Pages
```

## Как добавить модель

Модель — это ES-модуль с экспортами `defaults`, `controls`, `normalize`, `solve`, `formulas`, `steadyTable`, `chartSpecs` и, при необходимости, `extraBlocks` (см. `solow.js`). Название и описание модели задаются в `registry.js`; там же у модели появляется поле `load: () => import('./имя.js')`, и плитка становится активной.

## Тесты

`npm test` запускает все пять файлов `*.test.js`; те же тесты выполняются перед каждой публикацией сайта, и при ошибке сайт не обновляется.

```
node tests/fisher.test.js        # модель Фишера против аналитических решений (функция потребления, PIH, шоки)
node tests/solow.test.js         # модель Солоу: точное решение Бернулли, стационар, эффекты уровня и роста, золотое правило
node tests/ramsey.test.js        # стационар и седловая траектория против чисел из лекции, все комбинации настроек
node tests/ispcmpr.test.js       # IS–PC–MPR: аналитика Гали при RE, уравнения на траектории при любых ожиданиях, принцип Тейлора
node tests/consistency.test.js   # формулы на сайте (TeX блоков 1–3) против решателей всех моделей: подстановка чисел в каждое равенство
# дополнительные проверки модели Рамсея (запускаются вручную, печатают отчёт):
node tests/verify.mjs            # аналитические решения (ln, δ=1), сходимость по шагу и горизонту, инвариантность к сдвигу даты
python3 tests/independent_scipy.py   # независимый решатель на scipy (запускать после verify.mjs)
```
